# Apache Spark - Custom Image

> Version 4.1.2

My custom image to use Spark in Kubernetes and S3 and Delta Lake with Unity Catalog support.

## Usage

Check options with `make` command

```
$ make
help                           ❓ Show help menu
build-spark                    🐳 Build Spark image
build-operator                 🐳 Build Spark Operator image
buildx                         🐳 Build Multi-Arch and publish to registry
```
